# MML Studio

**좋아하는 음악을 마비노기 모바일에서 연주할 수 있는 MML 악보로 만들어 보세요.**

MML Studio는 **음원을 MML 악보로 변환하고, 편곡과 미리듣기까지 할 수 있는 Windows 프로그램**입니다.

음원에서 음표를 추출해 악보를 만드는 과정을 도와주며, 변환한 악보를 직접 다듬고 미리 들어보면서 원하는 연주를 준비할 수 있습니다.

> **MML이란?**
> 음의 높이와 길이, 쉼표 등을 문자로 표현한 악보 형식입니다.
> 마비노기 모바일에서 연주할 악보를 만들 때 사용합니다.

## 다운로드 및 설치

### [📥 통합 설치본 0.10.3 다운로드](https://github.com/gameicom/mmlStudio/releases/download/v0.10.3/MML_Studio_Setup_0.10.3_x64.exe)

**위 설치 파일 하나만 받으면 됩니다.** 릴리스 페이지에 있는 다른 ZIP이나 JSON 파일은 따로 다운로드하지 않아도 됩니다.

**지원 환경: Windows 10 / Windows 11, 64비트(x64)**

1. 위 링크에서 설치 파일을 다운로드합니다.
2. 다운로드한 `MML_Studio_Setup_0.10.3_x64.exe`를 실행해 설치합니다.
3. 설치가 끝나면 MML Studio를 실행하고, 전달받은 **실행 코드**를 입력합니다.

> **실행 코드 입력 안내**
> 실행 코드는 **대소문자를 구분**합니다. 전달받은 코드와 동일하게 입력해 주세요.
> 코드는 **프로그램을 실행할 때마다 다시 입력**해야 합니다.

[버전별 변경 사항 보기](https://github.com/gameicom/mmlStudio/releases)

## 이렇게 사용해 보세요

### 1. 음원에서 음표 추출하기

MML 악보로 만들고 싶은 음원을 불러와 음표를 추출합니다.

기본 설치본에 **CPU 음표 추출 기능**이 포함되어 있어, GPU 가속을 추가로 설치하지 않아도 작업을 시작할 수 있습니다.

### 2. MML 악보로 변환하고 다듬기

추출한 음표를 MML 악보로 변환하고, 필요한 부분을 편곡합니다.

음원에 따라 변환 결과가 달라질 수 있으므로, 원곡과 비교하면서 음이나 리듬을 다듬어 주세요.

### 3. 미리 듣고 연주 준비하기

**미리듣기**로 악보가 어떻게 연주되는지 확인합니다.

어색한 부분이 있다면 수정하고 다시 들어보세요. 완성한 MML 악보는 마비노기 모바일에서 연주하는 데 활용할 수 있습니다.

## GPU 가속은 꼭 필요한가요?

**아니요. GPU 가속은 선택 기능입니다.**

기본 설치본에는 미리듣기와 CPU 음표 추출에 필요한 구성 요소가 포함되어 있습니다. 처음에는 기본 설치만으로 사용할 수 있습니다.

GPU 가속을 사용하려는 경우에만 앱에서 해당 기능을 선택해 추가 파일을 내려받으면 됩니다. 기본 설치 과정에서 GPU용 파일을 자동으로 다운로드하지는 않습니다.

## 자동 업데이트

프로그램을 실행할 때 새로운 패치가 있는지 확인합니다.

일반적인 프로그램 수정은 자동 패치로 적용되므로, 업데이트할 때마다 설치 파일을 다시 받을 필요는 없습니다.

### 작업 중인 악보도 바뀌나요?

일반 패치는 **프로그램 코드**를 업데이트합니다.

이미 설치된 모델이나 작업 악보는 **일반 패치 대상에 포함되지 않습니다.**

### 업데이트에 문제가 생기면 어떻게 되나요?

패치의 서명과 파일 무결성을 확인하며, 업데이트한 새 버전이 시작되지 않으면 이전 버전으로 복구합니다.

인터넷에 연결되어 있지 않으면 업데이트를 받지 않고 현재 설치된 버전을 실행합니다.

### 업데이트가 바로 적용되지 않아요

이미 실행 중인 MML Studio가 있다면 **앱을 종료한 뒤 다시 실행**해 주세요. 실행 중인 앱이 종료되어야 패치를 적용할 수 있습니다.

## 릴리스 페이지의 다른 파일은 무엇인가요?

릴리스 페이지에는 설치 파일 외에도 자동 업데이트와 배포에 사용하는 파일이 함께 올라갑니다.

`mml-update.json`, `mml-app-*.zip`, `mml-patch-*.zip`, `release.json`은 런처와 배포 시스템에서 사용하는 파일입니다.

**처음 설치하는 분은 통합 설치 EXE 파일만 다운로드해 주세요.**
