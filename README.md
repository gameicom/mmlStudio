# MML Studio

마비노기 모바일용 MML 편곡과 미리듣기를 위한 Windows 프로그램입니다.

## 설치

- [통합 설치본 0.10.3 다운로드](https://github.com/gameicom/mmlStudio/releases/download/v0.10.3/MML_Studio_Setup_0.10.3_x64.exe): 이 설치 파일 하나만 사용하면 됩니다.
- [버전별 변경 사항](https://github.com/gameicom/mmlStudio/releases)

Windows 10/11 x64 환경을 대상으로 합니다. 기본 설치본에는 미리듣기와 CPU 음표 추출이 포함됩니다. GPU 가속은 앱에서 선택한 경우에만 추가로 내려받습니다.

프로그램을 실행할 때 전달받은 실행 코드를 입력하세요. 대소문자를 구분하며, 매 실행 시 다시 입력합니다.

## 자동 업데이트

앱을 실행할 때 새 패치를 확인합니다. 일반 프로그램 수정은 변경된 코드만 받으며, 여러 버전을 건너뛰는 경우 전체 앱 코드 ZIP을 받습니다. 설치된 모델이나 작업 악보는 일반 패치 대상에 포함되지 않습니다.

패치 서명과 파일 무결성을 확인하고, 새 버전이 시작되지 않으면 이전 버전으로 복구합니다. 인터넷 연결이 없으면 현재 설치된 버전을 실행합니다. 실행 중인 앱이 있으면 종료 후 다시 실행해야 패치를 적용할 수 있습니다.

`mml-update.json`, `mml-app-*.zip`, `mml-patch-*.zip`, `release.json`은 런처·배포용 파일입니다. 일반 사용자는 설치 EXE를 사용하세요.
